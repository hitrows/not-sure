# Not Sure — Windows-бета

Тот же плагин, что на macOS (см. `README-BETA.md` про сам звук и ручки).
Этот файл — только про то, что отличается на Windows.

---

## Совместимость

```
Формат: VST3, 64-bit
macOS-версия здесь не собирается — AU не существует вне Apple
Установщика нет — только .zip
```

Собран через GitHub Actions на реальной Windows-машине (`windows-latest`),
не кросс-компиляцией.

---

## Чего пока нет

- **Фабричных пресетов.** `.aupreset` — формат Apple, генератор пресетов —
  Objective-C++ под AudioToolbox. Ни то, ни другое не переносится на Windows
  в этом релизе. Ручки крутятся с нуля — как в самой первой macOS-бете.
- **Инсталлятора.** Только `.zip` с плагином и этим README. Полноценный
  инсталлятор (Inno Setup/WiX) — отдельная задача на потом.
- **Подписи.** Сертификат для Windows — отдельный от Apple, платный. Смотри
  ниже про SmartScreen.

---

## Установка

Распакуй `.zip`, скопируй `Not Sure.vst3` в:

```
C:\Program Files\Common Files\VST3
```

Перезапусти хост, если он был открыт.

### Если Windows ругается

Билд не подписан (та же ситуация, что с Gatekeeper на macOS, см.
`README-BETA.md`). При первом запуске SmartScreen, скорее всего, покажет
предупреждение «Windows защитила ваш компьютер» — нажми **«Подробнее»**,
затем **«Выполнить в любом случае»**.

## Это бета, и Windows-сборка — самая свежая часть беты

Собиралась и проверялась в первую очередь автоматически (компилируется,
проходит `pluginval`). Ручного прогона на живых хостах было меньше, чем на
macOS. Особенно интересно, если:

- плагин не грузится или падает при открытии
- редактор рисуется не полностью или криво (панель — большая склеенная
  картинка, на Windows это ни разу не проверялось)
- ручки/переключатели не в тех местах или не двигают параметр
- байпас или лампа не работают
- состояние не сохраняется/не восстанавливается с проектом
- звук щёлкает при автоматизации
